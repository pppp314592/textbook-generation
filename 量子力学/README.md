# 量子力学

- テーマ: 量子力学（波動関数、シュレーディンガー方程式、演算子形式、水素原子、スピン）
- 対象読者: 理工系大学生（初〜中級）
- レベル: 初〜中級（大学2〜3年）
- 前提知識: 線形代数、微積分、常微分方程式、複素数（第2章で復習）
- 想定学習時間: 40〜60時間
- 進行状況: 検証済み・PDF化済み（PDF 43ページ）（2026-08-02 最新情報調査完了: `調査/最新情報メモ.md` 参照）
