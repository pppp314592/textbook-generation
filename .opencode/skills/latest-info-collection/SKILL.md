# 最新情報収集スキル

教科書のテーマに関する最新情報を `info-researcher` サブエージェントに収集させる。

## テーマフォルダ構成

収集結果はテーマごとのフォルダに配置する。

```
{作業ディレクトリ}/
└── {テーマ名}/
    ├── README.md              # テーマ概要・進行状況（最新情報調査も記録）
    └── 調査/
        └── 最新情報メモ.md    # 収集結果（出典付き情報メモ）
```

- 対象のテーマフォルダが無い場合は作成する。
- 収集結果は `{テーマ名}/調査/最新情報メモ.md` に保存する。既に存在する場合は上書きせず、追記して更新日を更新する。

## 手順

1. **対象の確定**
   - 収集対象のトピック・キーワードと、教科書の対象レベル・公開想定時期を確認する。
   - テーマフォルダを特定する。教科書ファイルが既にあれば、本文の「現在も変わりうる記述」（統計、制度、技術仕様、バージョン等）から収集対象トピックを洗い出す。

2. **サブエージェントの起動**
   - `info-researcher` サブエージェントに以下を渡して調査を依頼する:
     - 調査トピックのリスト
     - 教科書の対象レベル（情報の深さを合わせるため）
     - 優先度（重要トピックは複数ソースで裏取り）
   - 並行して複数トピックを調査させる。

3. **結果の保存**
   - 収集結果（出典付き情報メモ）を `{テーマ名}/調査/最新情報メモ.md` に保存する。トピックごとに整理し、出典（URL・公表日・機関名）と収集日を必ず含める。
   - 信頼性の低いソースや矛盾する情報がないか確認する。

4. **結果の反映**
   - 教科書を更新するかはユーザーに確認する。更新する場合は、事実の記述に出典を添えて反映する。
   - 反映後は `README.md` の進行状況を更新し、必要に応じて content-verification スキルで整合性を確認する。

## 注意

- 収集した情報には必ず出典（URL・公表日・機関名）を付ける。
- 収集日（今日の日付）を明記する。
- ソース間で矛盾がある場合はその旨を報告し、独断で一方を採用しない。
