# ベイズ統計

- テーマ: ベイズ統計（条件付き確率、ベイズの定理、事前分布・事後分布、ベイズ推論、MCMC入門）
- 対象読者: 理工系大学生・初学者
- レベル: 初〜中級
- 前提知識: 高校数学（確率・微分・積分）。線形代数・最適化は最小限
- 想定学習時間: 40〜60時間
- 進行状況: PDF化済み（PDF 41ページ、ヘッダ・フッタなし、リンク検証0欠落、2026-08-02）

## 重要なゴール

- 条件付き確率とベイズの定理を理解し、逐次更新の考え方を身につける。
- 共役事前分布を使ったベイズ推論（ベルヌーイ・二項・正規・ポアソン）を手計算できる。
- 信用区間・ベイズ因子・多腕バンディットなど、頻度論と異なるベイズの判断基準を理解する。
- MCMCの原理とPython（PyMC等）による実践の入口を掴む。
