# 特殊相対論 最新情報メモ

- 収集日: 2026年8月2日
- 対象: 特殊相対論 教科書（理工系大学生・初学者向け）
- 収集方法: info-researcher サブエージェントによるweb検索・一次資料確認

## 総括

特殊相対論の核心的内容（光速不変・時間膨張・光速が上限等）に変更を迫る新事実はない。更新が必要なのは主に「数値・時期・事例の鮮度」（LHCエネルギー、CODATA公表年、2014年実験の紹介、2025年ACES、2026年LS3）のみ。

## トピック別メモ

### 1. 最新の精密検証実験（2020年代）

- Lorentz不変性の破れ（LIV）は2026年現在も一切検出されていない。全精密実験が特殊相対論の予言と整合
- 光格子時計の精度は10⁻¹⁹台に到達。単一イオン光時計比較でLIV係数を10⁻¹⁸レベルに制限（Sanner et al., Nature 2019）
- 回転超安定光共振器実験でSMEのLorentz破れパラメータを10⁻¹⁷精度で制限（Zhang et al., Phys. Lett. A 2021）
- 光速の等方性・不変性の現代版実験（Michelson-Morley型・Kennedy-Thorndike型）は異方性を10⁻¹⁷以下に制限
- 2025年、ESAのACES（原子時計アンサンブル）がISSへ打ち上げられ、時間膨張の検証を開始
- 出典: Sanner et al. Nature 2019 (https://www.nature.com/articles/s41586-019-0972-2)、NISTブログ 2026-02-25 (https://www.nist.gov/blogs/taking-measure/putting-einstein-test-worlds-most-accurate-clocks)
- 反映判断: 反映が必要（軽微）— 「2020年代の検証も破れなし、精度10⁻¹⁸級」を第8章に追記

### 2. LHCのエネルギーと運用状況（2025–2026）

- 設計エネルギー: 7 TeV/ビーム（重心系14 TeV）。ただし一度も7 TeV/ビームで運用されたことはない
- Run 2（2015–2018）: 6.5 TeV/ビーム（重心系13 TeV）
- Run 3（2022–2026）: 6.8 TeV/ビーム（重心系13.6 TeV）。世界記録
- Run 3は2026年5月19日に陽子-陽子衝突終了、6月29日にLHC停止 → Long Shutdown 3（LS3）開始
- HL-LHC（高輝度LHC）は2030年運転開始予定。エネルギーは13.6 TeVのまま、輝度を最大10倍に増強
- 出典: CERNプレス 2026-06-29 (https://home.cern/cern-bids-farewell-to-the-lhc-and-enters-long-shutdown-3/)、CERN Courier 2026-07-23 (https://cerncourier.com/the-lhc-completes-its-third-run/)、ATLAS/CERN 2022-07-05
- 反映判断: 反映が必要 — 「6.5→6.8 TeV」に更新、現在は長期停止中と明記

### 3. 物理定数のCODATA推奨値

- 最新はCODATA 2022（2025年4月30日公表, Rev. Mod. Phys. 97, 025002）
- 真空中の光速 c = 299 792 458 m/s は定義値のまま不変（CODATA 2022でも「Exact」）
- 重力定数 G = 6.674 30(15)×10⁻¹¹ m³ kg⁻¹ s⁻²（2018年版から変更なし）
- 2019年SI改定により、真空の透磁率 μ₀・誘電率 ε₀ は定義値から測定値へ変更（c = 1/√(ε₀μ₀) の関係自体は不変）
- 微細構造定数 α は2022年調整でわずかに更新
- 出典: NIST CODATA (https://physics.nist.gov/cgi-bin/cuu/Value?c)
- 反映判断: 現状のままで問題なし（α・μ₀等の微細な更新はコラム向き）

### 4. メートルの定義

- 現行定義（1983年・第17回CGPM決議1）が有効
- 2019年（第26回CGPM）に文言改定のみ（「光速 c の数値を 299 792 458 と固定することによって定義される」）。光速基準という本質は不変
- 2026年8月現在、メートル定義を変更する動きはない。秒の再定義（2030年目標）は進行中
- 出典: BIPM (https://www.bipm.org/en/si-base-units/metre)、NIST (https://www.nist.gov/si-redefinition/meter)
- 反映判断: 現状のままで問題なし（2019年文言改定と秒再定義の予定は脚注に可）

### 5. ミューオン・時間膨張に関する最近の実験

- 最も精密な直接の時間膨張検証は2014年のGSI（ダルムシュタット）実験: 7Li+イオン（β=0.338）を蓄積リングで分光し、時間膨張因子を2.3 ppbの精度で検証（Botermann et al., Phys. Rev. Lett. 113, 120405, 2014）
- 1977年CERNミューオン蓄積リング実験（γ=29.33、寿命約64 μs）は時間膨張を2×10⁻³精度で検証した歴史的実験
- 加速器実験・GPS・宇宙線ミューオンなどで時間膨張は常時確認されている
- 出典: Botermann et al. PRL 2014 (https://doi.org/10.1103/PhysRevLett.113.120405)、Bailey et al. Nature 1977 (https://www.nature.com/articles/268301a0)
- 反映判断: 反映が必要（軽微）— 2014年実験を「現在最も精密」として第8章に追加

### 6. 光速超えの報告（2011年OPERA騒動）

- 2011年9月、OPERA実験がミューニュートリノの光より約60 ns早い到着を報告（統計的有意度6.2σ）
- 2012年2〜3月、GPS受信機とマスタークロックをつなぐ光ファイバーコネクタの緩み（約73 ns）と発振器の周波数ずれ（約15 ns）の2つのハードウェア不具合が原因と判明。OPERA論文は撤回
- ICARUS・Borexino・LVDによる追試はすべて「光速と一致」（時間差は1 ns程度）
- その後、光速を超える信号の確立した報告は2026年現在までない
- 出典: CERNプレス 2012-02-23、Bertolucci et al. 2013 (DOI: 10.1016/j.nuclphysbps.2013.04.024)
- 反映判断: 現状のままで問題なし（「再測定で光速と一致」を明記すると一層正確）

### 7. GPS/GNSSでの相対論補正

- 基本数値は不変: 特殊相対論（軌道速度3.87 km/s）で衛星時計は約7 μs/日遅れる、一般相対論（高度約20,200 km）で約45 μs/日進む、正味約+38 μs/日
- 補正しないと1日約10 kmの位置誤差
- 補正方法: 衛星搭載時計の発振周波数を打ち上げ前に低めに設定（10.23 MHz → 10.22999999543 MHz、相対周波数オフセット −4.464×10⁻¹⁰）
- 全GNSS（GPS・GLONASS・Galileo・BeiDou）が同様の相対論補正を適用
- 新展開: 2025年4月にESAのACESがISSへ打ち上げ（PHARAO原子時計搭載、地上-宇宙間の時刻比較精度を10⁻¹⁶台へ）
- 出典: ESA Navipedia (https://gssc.esa.int/navipedia/index.php/Relativistic_Clock_Correction)、Ashby, Living Reviews in Relativity 2003、NIST 2026
- 反映判断: 現状のままで問題なし（ACES・秒再定義はコラムに可）
