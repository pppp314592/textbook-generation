# Makefile 実践入門

- 対象読者: 中級者（Makefileを触ったことがあるが、より高度な活用法を学びたい方）
- レベル: 中級
- 想定学習時間: 10〜15時間（1章あたり1〜2時間＋練習問題）
- 進行状況: 検証済み・PDF化済み（PDF 40ページ）
- 基準バージョン: GNU Make 4.4.1（2023年2月26日リリース、調査時点2026年7月の最新安定版）

## 章立て

| 章 | タイトル | 内容 |
|---|---|---|
| 序章 | なぜ今、Makefileなのか | Makeの歴史、他のビルドツールとの比較、Makeが今も使われる理由 |
| 1章 | Makefileの基本構造 | ルール構文、ターゲット・前提条件・レシピ、TAB、デフォルトゴール、`.PHONY` |
| 2章 | 変数の理解がすべて | 代入演算子の種類、再帰展開vs即時展開、自動変数 |
| 3章 | ルールの高度な使い方 | パターンルール、静的パターンルール、グループ化ターゲット、二次展開、暗黙ルール |
| 4章 | 関数とマクロ | wildcard/foreach/call/eval/shell、4.4の新関数 let/intcmp |
| 5章 | 並列ビルドとデバッグ | -j、output-sync、ジョブサーバー、.WAIT、--shuffle、--debug |
| 6章 | 依存関係自動生成と実践パターン | GCC -MMD -MP、.dファイル、インストール用ターゲット、GNU Coding Standards |
| 7章 | プラットフォーム対応と落とし穴 | Linux/macOS/Windowsの差異、シェル依存、再帰make、後方非互換、POSIX |
| 付録 | 練習問題の解答、用語集、出典一覧 | |

## ファイル構成

```
Makefile/
├── README.md           # 本書（このファイル）
├── 教科書.md           # 教科書本体（Markdown）
├── 検証レポート.md      # 内容検証の結果
├── 調査/
│   └── 最新情報メモ.md # 最新情報収集の結果
├── 印刷用/
│   ├── 教科書-印刷版.html
│   └── 教科書.pdf
└── assets/             # 画像等のリソース
```
