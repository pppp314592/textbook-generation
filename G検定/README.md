# G検定入門 教科書

## テーマ概要

JDLA（一般社団法人日本ディープラーニング協会）が実施する **G検定（JDLA Deep Learning for GENERAL）** の合格を目指す学習者のための入門教科書。AI・ディープラーニングの基礎知識を体系的に学び、ビジネス現場でAIを活用するためのリテラシーを身につけることを目的とする。

## 対象読者・レベル

- 対象: AI・ディープラーニング未経験者、ビジネスパーソン、文系・理系を問わず
- レベル: 初級〜中級
- 想定学習時間: 30〜50時間

## 章立て

1. はじめに（G検定とは・本書の使い方）
2. 人工知能とは（定義・AI効果・議論される問題）
3. 人工知能をめぐる動向（3次ブーム・探索/推論・エキスパートシステム）
4. 機械学習の基礎（教師あり/なし/強化学習・モデル評価）
5. ディープラーニングの概要（NN・活性化関数・誤差逆伝播・最適化）
6. ディープラーニングの要素技術と応用例（CNN/RNN/Attention/生成AI/転移学習）
7. AIの社会実装（プロジェクト進め方・データの収集/加工）
8. AIに必要な数理・統計
9. AIに関する法律と契約（個人情報保護法・著作権法ほか）
10. AI倫理・AIガバナンス
11. 総まとめと合格戦略
付録: 練習問題の解答 / 用語集 / 資格対応
